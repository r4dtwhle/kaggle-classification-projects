# 📂 Data — Online Shoppers Revenue Prediction

File data **tidak disertakan** di repository ini karena berasal dari kompetisi Kaggle (kelas Data Mining).

Untuk menjalankan notebook, letakkan file berikut di folder ini:

| File | Keterangan |
|---|---|
| `train.csv` | 8.631 baris, 21 kolom (termasuk target `Revenue`) |
| `test.csv` | 3.699 baris, 21 kolom (tanpa target) |
| `sample_submission.csv` | Format submisi (`Id`, `Revenue`) |

Dataset ini merupakan versi modifikasi dari **[Online Shoppers Purchasing Intention Dataset (UCI)](https://archive.ics.uci.edu/dataset/468/online+shoppers+purchasing+intention+dataset)** dengan tambahan kolom `PageLoadTime`, `AvgTimePerPage`, dan `VisitorCohort`.
