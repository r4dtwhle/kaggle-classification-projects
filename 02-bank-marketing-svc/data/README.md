# 📂 Data — Bank Marketing Term Deposit Prediction

File data **tidak disertakan** di repository ini karena berasal dari kompetisi Kaggle (kelas Data Mining).

Untuk menjalankan script, letakkan file berikut di folder ini:

| File | Keterangan |
|---|---|
| `train.csv` | 22.916 baris, 22 kolom (termasuk target `berlangganan_deposito`) |
| `test.csv` | 5.729 baris, 21 kolom (tanpa target) |

Dataset ini merupakan versi modifikasi (nama kolom berbahasa Indonesia + kolom `pulau`) dari **[Bank Marketing Dataset (UCI)](https://archive.ics.uci.edu/dataset/222/bank+marketing)**.
